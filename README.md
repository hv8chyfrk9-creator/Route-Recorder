# Route Recorder

Grabador de recorridos standalone para Roblox (Delta Executor / móvil).

**No depende de Delta Hub.**

## Cómo usar

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/hv8chyfrk9-creator/Route-Recorder/main/route_recorder.lua"))()
```
